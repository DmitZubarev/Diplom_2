## Дипломный проект. Задание 2: API-тесты

### Автотесты для проверки API программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы API-тесты, покрывающие методы:
- `POST api/auth/register` - создание пользователя
- `POST api/auth/login` - авторизация пользователя
- `PATCH api/auth/user` - обновление информации о пользователе
- `POST api/orders` - создание заказа
- `GET api/orders` - получение заказов конкретного пользователя

### Структура проекта

- `resources` - основной пакет, содержащий субпакеты с шагами, схемами и т.д.
- `helpers` - пакет, содержащий http-клиент, валидатор ответов и вспомогательные функции
- `tests` - пакет, содержащий тесты

### Запуск автотестов

**Установка зависимостей**

>  `$ pip install -r requirements.txt`

**Запуск всех тестов**

>  `$ pytest -v`

**Запуск всех тестов с отчетом**

>  `$ pytest -v --alluredir=allure_results`

**Просмотр отчета**

>  `$ allure serve allure_results`
